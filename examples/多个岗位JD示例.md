# 多岗位JD对比示例（政策与金融研究方向）

> 使用方法：复制下方“岗位：”开始的全部内容，粘贴到网站的“多岗位横向比较”输入框。岗位之间使用单独一行 `---` 分隔。所有内容均为合成演示。

岗位：证券研究所｜经济政策与国际关系组实习生

【工作内容】
1. 协助完成政策和国际局势跟踪、海外资料翻译、研究报告写作、数据处理与图表制作；
2. 维护地缘政治研究资料库，参与会议听录和专题研究。

【任职要求】
1. 国际关系、政治学、经济学等专业硕士在读；
2. 每周至少4天并连续实习3个月；
3. 英文阅读和中英文写作能力扎实；
4. 熟练使用Excel和PowerPoint，熟悉Wind、Python或AI研究工具者优先。

【加分项】
有券商行研、政策研究、会议纪要或研究写作经历。支持北京、上海线下及协商远程。

岗位：公募基金｜宏观策略研究实习生

【工作内容】
1. 跟踪国内外宏观经济数据、货币政策与财政政策；
2. 协助维护宏观数据库、制作晨报图表并参与大类资产专题研究；
3. 整理研究会议观点和市场一致预期变化。

【任职要求】
1. 经济学、金融学等专业硕士在读；
2. 具备宏观经济学和金融市场基础；
3. 熟练使用Excel、Wind，能够使用Python处理时间序列数据；
4. 每周至少4天，连续实习3个月。

【加分项】
有宏观策略、资产配置研究或高质量课程论文。工作地点为上海。

岗位：管理咨询公司｜公共政策研究实习生

【工作内容】
1. 参与产业政策与区域发展项目；
2. 搜集政府文件、行业报告和企业资料；
3. 开展专家访谈纪要整理、案例研究及报告撰写；
4. 协助制作客户汇报材料和项目数据库。

【任职要求】
1. 公共政策、经济学、社会学或相关专业；
2. 信息搜集、结构化分析和PowerPoint表达能力强；
3. 能够快速阅读中英文资料并按期交付；
4. 可连续实习3个月。

【加分项】
有咨询、智库、政府课题或商业研究经历。工作地点为北京，可部分远程。

岗位：高校智库｜国际关系研究助理

【工作内容】
1. 跟踪国际安全、全球治理和区域国别议题；
2. 整理海外智库观点，协助完成文献综述；
3. 参与学术活动听录、研究资料库建设及课题成果编辑。

【任职要求】
1. 国际关系、政治学或区域国别研究方向硕士在读；
2. 英文文献阅读和学术写作能力良好；
3. 工作严谨，能够进行长期资料维护；
4. 每周至少3天。

【加分项】
掌握定量研究方法、文本分析或第二外语。工作方式为校内线下与远程结合。

---

岗位：金融数据公司｜研究数据运营实习生

【工作内容】
1. 整理宏观、政策和产业数据，维护研究标签与数据口径；
2. 检查数据质量，记录异常并跟进修正；
3. 协助研究员制作可视化看板和专题数据包。

【任职要求】
1. 经济、金融、统计或信息管理相关专业；
2. 熟练使用Excel，了解SQL或Python；
3. 对政策和金融市场信息敏感；
4. 细致负责，能够处理重复性数据核验工作。

【加分项】
使用过Wind、同花顺、Power BI或爬虫工具。工作地点为上海，每周至少4天。
